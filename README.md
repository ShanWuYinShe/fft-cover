# 傅立叶指针 · 旋转连杆挑战

基于傅立叶变换的收集小游戏：把最多 10 根不同半径的旋转指针**首尾相连**，它们的合成轨迹就是一条傅立叶级数曲线——调整各指针的半径、频率（负数 = 反转）与相位，让指尖在旋转中**经过尽可能多的目标点**。

## 技术栈

- [Svelte 5](https://svelte.dev)（runes 响应式）+ TypeScript
- [Vite](https://vite.dev) 构建，[Vitest](https://vitest.dev) 单测
- Canvas 2D 渲染（requestAnimationFrame 命令式循环），UI 面板为响应式组件
- 包管理：pnpm（registry 走 npmmirror）

## 玩法

1. 右侧面板勾选启用指针（⟲ 按钮切换旋转方向，点击数值精确输入）；**每关有指针上限**（圆 1 根、椭圆 2 根、心形 8 根……），上限恰好容纳该关的精确傅立叶分解；编辑态可直接**拖拽画布关节**调半径与相位（实时显示数值）
2. 拖动滑块调整每根指针的半径 / 频率 / 相位：**暗金虚线**是目标曲线参考，**紫色虚线**是你当前参数的合成轨迹——逼近它！
3. 点「▶ 开始旋转」，指针真实旋转，尖端每扫过一个点即点亮计分；**1.2 秒内连续收集触发连击**，点分 = 100 × (1 + 连击数)，按关记录最佳得分
4. 收集音效是**古筝式拨弦**，按本关五声音阶递进；全部收齐奏响 C 大三和弦琶音（傅立叶 = 谐波 = 和声）
5. 跑完 2 个基础周期（或按 S）结算星级：收集 ≥90% 三星、≥65% 二星、≥35% 一星；结算后可「👁 查看轨迹」回看，点画布恢复
   「📅 每日」按**当前随机难度**生成今日关卡（seed = 日期+难度，同难度全球同关，按日与难度记最佳）；「🎲 随机」支持简单/普通/困难三档——普通可完美拟合，**困难关含超出指针上限的分量，只能尽量逼近**；随机关有**邀请码**：复制发给好友，或输入邀请码重建同一关卡
6. 编辑态可直接**拖拽画布上的关节**调整半径与相位（滑块之外的第二种手感，支持触屏）；拖滑块时对应关节会在画布上金色高亮
7. 收集全部点会触发金色冲击波特效
8. 「🧪 沙盒」模式：无限时自由旋转，边转边实时调参扫点，成绩不计入记录；可切**转速档位**（0.5×/1×/2×）；「🪄 自动拟合」按目标频谱直接解出精确参数并以动画演示傅立叶逐项逼近；画布右上角的**频谱仪**实时显示你的傅立叶系数（青=正频、紫=负频）
9. 全清一关会记录**最快全清用时**（⚡ 竞速目标），结算面板与「本次成绩」中可见
10. 指针面板的「🎲 随机参数 / ⭯ 清零」帮你快速起步；「▶ 回放解法」一键载入上届那局的指针配置并立即旋转；音效开关偏好会被记住
11. 结算浮层可「📋 复制战报」：关卡、星级、得分、全清用时与解法参数一键分享（随机关附邀请码）
12. **👻 上届竞速**：运行中上届解法的轨迹以金色虚线同屏显示，收集胶囊下方还会实时告诉你**比上届同一时刻多收还是少收了几点**（进度条上的金色刻度＝上届此刻的收集比例），结算卡给出"上届同期 ±N 点"；首次访问有新手引导
13. **🎵 探索未知的环境声**：没有持续低鸣，只有稀疏、偶发、带空旷混响的声音——远方信号每隔几秒飘出一个长起长落的音；**指针真的转起来时才化为声部**（频率→音高、半径→音量、相位→左右），编辑思考时保持安静。点运行栏的 🎵 可开关（偏好会被记住）
14. **🗺 战役结构**：15 个内置关卡分成五个章节（**一画 / 花信 / 阴阳 / 万象 / 器象**）；关卡面板**一次只展开一章**（◀ ▶ 翻页 + 章节圆点），后续章节显示为「？？？」不剧透；**全部 15 关拿到星即通关**，弹出结局面板（🏁 通关 / 🏆 全三星"谐波大师"两种）
15. **♪ 每章一个调性**：五章正好用满中国五声调式——**C 宫五声 / A 羽五声 / D 商五声 / E 角五声 / G 徵五声**；切章时指针声部、收集音效、环境音一起转调，切关会有一声柔和的"抵达"泛音
16. **🧭 本关目标（四枚朱印）**：左侧「本关目标」列出这一关的四项追求——**星 三星 / 满 完美全清 / 准 精确解 / 专 专家全清**；达成即盖朱砂印，未达成会显示"现在离它多远"（例如「当前拟合度 73% · 需 ≥99%」）
17. **🔁 续玩**：刷新或关掉浏览器再回来，会**自动回到上次玩的那一关**——「继续游戏」真的接着上次；随机关按邀请码复现、每日挑战按当天重建，进度存档也会带上这一项
18. **🚪 入境卡**：第一次进入某一章会弹一张「入境」卡，写清**这一章教什么**（例如第三章：正频与负频成对出现）与本章调性；看过一次就不再打扰。第一章交给新手引导，不弹卡

快捷键：空格 开始/暂停（结算后空格立即重开）· S 停止结算 · R 重置。

## 战役与结局

内置关卡不是一串并列按钮，而是一条通关路线：

章名取中国古典意象（一画开天、花信有风、一阴一阳、万象森罗、器物成象），数学含义写在章内提示里；五章正好用满**中国五声调式**。

| 章节          | 调性     | 关卡                           | 主题                                           |
| ------------- | -------- | ------------------------------ | ---------------------------------------------- |
| 第一章 · 一画 | C 宫五声 | 圆、椭圆                       | 易有太极，是生两仪——一根指针就是一个旋转向量   |
| 第二章 · 花信 | A 羽五声 | 三叶草、梅花、八齿齿轮         | 花信有风，开合有时——反着转的那一根才是关键     |
| 第三章 · 阴阳 | D 商五声 | 无穷 ∞、利萨茹 3:2、利萨茹 5:4 | 一阴一阳之谓道——正频与负频总是成对出现         |
| 第四章 · 万象 | E 角五声 | 九瓣花、五角星、心形、十二波纹 | 万象森罗，皆可展开——高次谐波与"拟合不了的曲线" |
| 第五章 · 器象 | G 徵五声 | 盘长结、菱花镜、阴阳鱼         | 五音既全，器物成形——2 / 5 / 8 根指针各教一件事 |

- **解锁**：前一关拿到至少 1★ 才能进入下一关（规则集中在 `src/lib/game/campaign.ts`，面板与判定同源）；第五章紧接第四章的「十二波纹」之后解锁
- **中国器物三关（第五章 · 器象）**：
  - **盘长结**（2 根）——2× 顺转 + 1× 反转，频率比决定结的形状
  - **菱花镜**（5 根）——6× 与 9× 两级谐波叠在 1× 主圆上，还原唐代八瓣镜缘
  - **阴阳鱼**（8 根）——右半外圆 + 解析 S 曲线（过圆心、两极相切），±1×~±4× 全部上阵
- **一次只看一章**：关卡面板按章节翻页（◀ ▶ 与章节圆点），章内是一关一节点的纵向路径；**未解锁的章节只显示「🔒 ？？？」和"通关上一关后解锁"**，不提前剧透后面的曲线与章节名——关卡类游戏的进度感来自"看不见前面有什么"
- **入境卡**：每章第一次进入时给一张卡片，说明本章要点与调性（不打断第一章的新手引导）
- **章头两条进度**：章节名下方同时显示「★ 6/9」（星）与「印 5/12」（四枚朱印的精通进度），把精通也变成地图上看得见的东西
- **通关**：全部内置关卡 ≥1★ → 结局面板「🏁 通关！」；全部 3★ → 「🏆 谐波大师」
- 结局只在**状态跨级的那一局**弹出一次（重复游玩不会反复弹），面板上同时给出总星数 / 完美全清 / 精确解 / 专家全清进度，并指出下一步追求
- 「📅 每日挑战 / 🎲 随机关 / 🎨 创作」收在关卡表下方的「更多玩法」里，始终可进入

## 音效与音乐

傅立叶级数本来就是声音的语言，所以声音不是装饰，而是**同一套数学的听觉通道**。配乐的目标听感是"探索未知"：**没有持续低鸣**，只有稀疏、偶发的声音和一片空旷的空间，安静下来几乎只剩空间感。

| 层次     | 听感                                       | 实现                                                                                                                   |
| -------- | ------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------- |
| 远方信号 | 每隔几秒飘出一个长起长落的音，像远处的钟声 | **编钟式泛音**（1 : 2 : 2.76，高次压到 8%）+ 从本关调性音阶取音（上限 700 Hz）；起音 0.8~2.6 秒、消散 4~9 秒、随机声像 |
| 你的指针 | 转起来时，指针化为缓慢呼吸的声部           | 频率 \|k\| → 第 k 次谐波；半径 → 音量；相位 → 声像 sin(φₖ)；方向 → ±7 音分失谐（±k 对产生拍音）                        |
| 空气     | 空间本身的流动感（不是"嘶嘶"）             | 带通 420 Hz + 低通 900 Hz 的极轻噪声，滤波频率以 0.03 Hz 缓慢摆动                                                      |
| 空间     | 空旷、遥远                                 | 混响（3.6 秒指数衰减脉冲响应）+ 带阻尼的反馈延迟，干湿并联                                                             |
| 收集     | **古筝式拨弦**，音阶上行                   | 极快起音（6 ms）+ 指数衰减 + 三个泛音（1 : 0.3 : 0.12），整体低通 3 kHz；全清奏 C 大三和弦琶音                         |

**不刺耳是硬约束**（高频纯音叠起来最容易扎耳朵）：

- 高次谐波按 `1 / (1 + 0.3(k-1))` 衰减——10× 只剩基频的 27%，16× 只剩 19%
- 总线低通 1300 Hz；环境音上限 900 Hz；空气层再低通一次去掉嘶声
- 实测 10 根指针同时发声，2.5 kHz 以上的能量占比约 **1%**（36 dB/oct 测量）

**每章一种中国五声调式**：C 宫五声 / A 羽五声 / D 商五声 / E 角五声——五声无半音、无导音，本身就温润；切章时指针声部、收集音效、环境音一起转调，切关另有一声柔和的"抵达"泛音（编钟泛音）；随机关与每日关按邀请码稳定散列挑调性（同一关卡每次进来都一样）。微调式（徵）留给后续章节。

浏览器自动播放策略要求手势，故音乐与音效在**首次点击/按键后**才起播（起播时会立刻同步当前状态）；切到后台自动挂起，排程同时暂停以免在挂起期间堆叠。

## 数学原理

指针链尖端位置（复平面表示）：

    P(t) = Σₖ rₖ · e^(i·ωₖ·t + φₖ)，ωₖ = 2π·fₖ / T0

这正是傅立叶级数的合成形式。任意周期曲线都可分解为有限个旋转向量之和——玩家的任务就是逆向找出这组系数。

## PWA

线上为可安装的 PWA：手机浏览器菜单「添加到主屏幕」后可全屏运行，**离线也能玩**。

- `public/manifest.webmanifest` — standalone 显示、深色主题、192/512/maskable 图标
- `public/sw.js` — Service Worker：
  - 导航与 manifest：**network-first**（保证新版本可见），断网回退缓存
  - `/assets/*`、图标：**cache-first**（文件名带指纹，内容不可变）
- 图标由 `icon.svg` 通过 headless Chrome 栅格化生成（192/512/180/32）
- 仅生产构建注册 SW（dev 下不注册，避免缓存干扰开发）

## 部署（workwork-server）

线上地址：**https://game.chaoset.com/**（CF 橙云代理，源站 IPv6-only）。

- 服务器目录 `~/games/`，compose 挂 `ipvlan_docker` 外部网络，静态 IPv6 `…:1::60`（next free was ::60；::10 面板 / ::12 xray / ::20 hotspot / ::30 ops / ::40 media / ::50 music）
- 证书：chaoset.com 通配符（CF Origin CA），归档 `~/work/dogod/cf_token_and_cert/chaoset.com/`；另有 Cloudflare origin-pull CA（`cloudflare-origin-pull-ca.pem`，CF 公开证书）放服务器 `~/games/cert/cloudflare-origin-pull.pem`，供 `ssl_verify_client`（Authenticated Origin Pulls）校验 CF 回源
- DNS：`game.chaoset.com` AAAA → `…:1::60`（橙云）。**服务器 IPv6 前缀轮换时需更新此记录**（可参照 workwork 面板的轮换同步逻辑）
- 新增游戏（两种方式）：
  - 子路径（推荐）：`sites/` 下加 `<game>/` 静态目录，游戏构建时以 `/<game>/` 为 base（Vite 系 `VITE_BASE=/<game>/` 或 `vite build --base=/<game>/`），在 `deploy/nginx-game.chaoset.com.conf` 加一段 `location ^~ /<game>/ `（alias + try_files + 无尾斜杠 301，参照现有 travel/cnm/wave-warden 三段），`docker compose exec nginx nginx -s reload`
  - 独立子域：复制 server 块改 root/server_name，另配 DNS 记录

更新上线流程：

```bash
pnpm build && scp -r dist workwork-server:/tmp/fft-cover-dist
ssh workwork-server "rm -rf ~/games/sites/fft-cover && mv /tmp/fft-cover-dist ~/games/sites/fft-cover"
```

首次部署（服务器无 ~/games 时）：

```bash
ssh workwork-server "mkdir -p ~/games/nginx/conf.d ~/games/cert ~/games/sites"
scp deploy/docker-compose.yml workwork-server:~/games/docker-compose.yml
scp deploy/nginx-game.chaoset.com.conf workwork-server:~/games/nginx/conf.d/games.conf
scp ~/work/dogod/cf_token_and_cert/chaoset.com/cert.pem ~/work/dogod/cf_token_and_cert/chaoset.com/cert.key workwork-server:/tmp/
ssh workwork-server "mv /tmp/cert.pem ~/games/cert/chaoset.pem && mv /tmp/cert.key ~/games/cert/chaoset.key && chmod 600 ~/games/cert/chaoset.key"
scp ~/work/dogod/cf_token_and_cert/cloudflare-origin-pull-ca.pem workwork-server:/tmp/
ssh workwork-server "mv /tmp/cloudflare-origin-pull-ca.pem ~/games/cert/cloudflare-origin-pull.pem"
ssh workwork-server "cd ~/games && docker compose up -d"
```
