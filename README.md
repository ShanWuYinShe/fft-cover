# 傅立叶指针 · 旋转连杆挑战

基于傅立叶变换的收集小游戏：把最多 10 根不同半径的旋转指针**首尾相连**，它们的合成轨迹就是一条傅立叶级数曲线——调整各指针的半径、频率（负数 = 反转）与相位，让指尖在旋转中**经过尽可能多的目标点**。

## 技术栈

- [Svelte 5](https://svelte.dev)（runes 响应式）+ TypeScript
- [Vite](https://vite.dev) 构建，[Vitest](https://vitest.dev) 单测
- Canvas 2D 渲染（requestAnimationFrame 命令式循环），UI 面板为响应式组件
- 包管理：pnpm（registry 走 npmmirror）

## 玩法

1. 右侧面板勾选启用指针（⟲ 按钮切换旋转方向，点击数值精确输入）；**每关有指针上限**（圆 1 根、椭圆 2 根、心形 8 根……），上限恰好容纳该关的精确傅立叶分解；编辑态可直接**拖拽画布关节**调半径与相位（实时显示数值）
2. 拖动滑块调整每根指针的半径 / 频率 / 相位：**暗金虚线**是目标曲线参考，**紫色虚线**是你当前参数的合成轨迹——逼近它！
3. 点「▶ 开始旋转」，指针真实旋转，尖端每扫过一个点即点亮计分；**1.2 秒内连续收集触发连击**，点分 = 100 × (1 + 连击数)，按关记录最佳得分
4. 收集音效是**古筝式拨弦**（带上滑音装饰），按本关五声音阶递进；连击每满 5 敲一声**木鱼**；全部收齐奏响**本关调性的古筝刮奏**（五声上行一行，傅立叶 = 谐波 = 和声）
5. 跑完 2 个基础周期（或按 S）结算星级：收集 ≥90% 三星、≥65% 二星、≥35% 一星；结算后可「👁 查看轨迹」回看，点画布恢复；收起后运行栏会出「📊 结算卡」按钮，随时重开成绩卡（复制战报 / 下一关都在）
   「📅 每日」按**当前随机难度**生成今日关卡（seed = 日期+难度，同难度全球同关，按日与难度记最佳），旁边有「📤」分享今日挑战；「🎲 随机」支持简单/普通/困难三档——普通可完美拟合，**困难关含超出指针上限的分量，只能尽量逼近**；随机关有**邀请码**与**分享链接**：复制邀请码给好友手输，或点「📤 分享」直接把链接发过去（链接里带难度，好友打开即面对同一条曲线）。**邀请码行常驻**（不再只在随机关才显示）：输入框认三种码——随机关种子（`777`）、每日难度（`hard` / `困难`）、创作关系数串（`1:80:0,3:55:0`）；创作关与随机关的「🔗 复制 / 📤 分享」各自给出对的码与链接（创作关分享 `#c=<系数串>`，好友打开即进同一关）
6. 编辑态可直接**拖拽画布上的关节**调整半径与相位（滑块之外的第二种手感，支持触屏）；拖滑块时对应关节会在画布上金色高亮
7. 收集全部点会触发金色冲击波特效
8. 「🧪 沙盒」模式：无限时自由旋转，边转边实时调参扫点，成绩不计入记录；可切**转速档位**（0.5×/1×/2×）；「🪄 自动拟合」按目标频谱直接解出精确参数并以动画演示傅立叶逐项逼近；画布右上角的**频谱仪**实时显示你的傅立叶系数（青=正频、紫=负频）
9. 全清一关会记录**最快全清用时**（⚡ 竞速目标），结算面板与「本次成绩」中可见
10. 指针面板的「🎲 随机参数 / ⭯ 清零」帮你快速起步；「▶ 回放解法」一键载入上届那局的指针配置并立即旋转；音效开关偏好会被记住
11. 结算浮层可「📋 复制战报」：关卡、星级、得分、全清用时与解法参数一键分享（随机关附邀请码）；「📸 保存成绩图」导出的是**画布当前帧 + 成绩条**——成绩条上有星级、收集/拟合度、**本关四枚朱印**（达成的填朱砂）与邀请码
12. **👻 上届竞速**：运行中上届解法的轨迹以金色虚线同屏显示，收集胶囊下方还会实时告诉你**比上届同一时刻多收还是少收了几点**（进度条上的金色刻度＝上届此刻的收集比例），结算卡给出"上届同期 ±N 点"；首次访问有新手引导
13. **🎵 探索未知的环境声**：**全曲没有任何持续音**——指针声部不再是常鸣长音（持续正弦叠加听久了就是"嗡嗡"），而是**一阵阵柔和的风铃脉冲**：每根启用指针按自己的节拍（1.6~3.6 秒）敲一下，频率→音高（超 700 Hz 自动降八度保住谐波关系）、半径→音量、相位→左右；远方信号是每隔几秒飘出的**上行五声琶音**（2~3 音一组的动机，正向明快），组与组之间留足安静。混响收短到 1.4 秒、回声只留单次且很轻；一切实际发声都压在 700 Hz 以下、总线低通 900 Hz。编辑思考时指针保持安静，转起来才敲出织体。点运行栏的 🎵 可开关（偏好会被记住）
14. **🗺 战役结构**：21 个内置关卡分成七个章节（**一画 / 花信 / 阴阳 / 万象 / 器象 / 巧变 / 大成**）；关卡面板**一次只展开一章**（◀ ▶ 翻页 + 章节圆点），后续章节显示为「？？？」不剧透；**全部 21 关拿到星即通关**，弹出结局面板（🏁 通关 / 🏆 全三星"谐波大师"两种）
15. **♪ 每章一个调性**：五章正好用满中国五声调式——**C 宫五声 / A 羽五声 / D 商五声 / E 角五声 / G 徵五声**；切章时指针声部、收集音效、环境音一起转调，切关会有一声柔和的"抵达"泛音
16. **🧭 本关目标（四枚朱印）**：左侧「本关目标」列出这一关的四项追求——**星 三星 / 满 完美全清 / 准 精确解 / 专 专家全清**；达成即盖朱砂印，未达成会显示"现在离它多远"（例如「当前拟合度 73% · 需 ≥99%」）。**结算时本局新盖的印会一枚一枚盖下来**（配"盖章"音：印面落纸的一声闷响 + 一声轻铃），卡片同时给出本关朱印进度
17. **🧧 章节印**：把一章全部关卡的 4 枚朱印集齐（例如第一章 2 关 = 8 枚），该章就盖上一方**章节印**（画 / 信 / 阳 / 象 / 器 / 巧）——地图章头常驻这方印，集齐那一局的结算卡上会隆重盖一次（更沉的一声重章 + 两声轻铃）
18. **🔁 续玩**：刷新或关掉浏览器再回来，会**自动回到上次玩的那一关**——「继续游戏」真的接着上次；随机关按邀请码复现（**连难度一起记住**，否则换难度会复现出另一条曲线）、每日挑战按当天重建，进度存档也会带上这一项；**创作关也能续玩**（系数会存进进度档，刷新后原样回来；换到别的关会自动清掉，不会很久之后突然跳回去）
19. **🔗 分享链接**：随机关卡可一键分享——链接形如 `…/#r=random-777-hard`；每日挑战也可分享（`…/#d=hard`，只带难度，日期由打开那天决定，"今天分享明天打开就是明天那关"）。好友打开直接进对应关卡（自动跳过开始画面、清掉 hash 防止刷新重复载入）；同一标签页里粘贴新链接也会立刻生效（监听 hashchange）
    - 链接发出去有**社交预览卡**：`index.html` 里的 og / twitter 元信息 + `public/og.png`（1200×630，浏览器按真实曲线渲染后导出）
    - **解法挑战链接会带上关卡**：`#r=<邀请码>-<难度>&arms=<解法码>` / `#d=<难度>&arms=…` / `#c=<系数串>&arms=…`。只带 `#arms=` 时，好友打开只是"他自己那一关"套上你的参数——随机关/每日关/创作关会因此对不上题（内置关无需标识，好友本地就有那一关）
20. **🚪 入境卡**：第一次进入某一章会弹一张「入境」卡，写清**这一章教什么**（例如第三章：正频与负频成对出现）与本章调性；看过一次就不再打扰。第一章交给新手引导，不弹卡
21. **📅 每日挑战的 7 日格**：每日挑战按钮下方是一排最近 7 天的小格——打过的填朱砂（带 ✓），今天描青边，右侧写连续天数；按钮右侧显示**今日最佳**（同一天各难度取最高）
22. **📖 图鉴**：成就面板新增「图鉴」页——七章 21 关的曲线缩略图一次排开，点亮过的显示真实轮廓 + 星级 + 四枚朱印，未解锁的仍是「？？？」（继续不剧透）
23. **⭐ 运行中的星级反馈**：收集比例越过 35% / 65% / 90% 时，画布顶部实时点亮一档星（升档弹一下 + 一声清亮铃音，音高随档位升高），不用等结算就知道这局拿到了几星
24. **🧭 结算页的「下一枚印」**：按推荐顺序（星 → 满 → 准 → 专）指出第一枚还没拿到的印，并说清还差什么——例如「下一枚印 精确解 · 当前拟合度 98% · 需 ≥99%」。**整行可点，直接落到那个动作**：
    - 专 → 「开启专家模式 →」：开专家模式并回到调参界面，立刻可以再战
    - 准 → 「对比频谱 →」：打开目标频谱叠加，看清差在哪一项
    - 星 / 满 → 「看轨迹 →」：收起结算浮层、保留本局轨迹，**漏掉的点用红圈脉冲高亮**，画布底部给出「漏了 N 点（红圈）· 点画布返回结算」——一眼看清差在哪几个点
    - 三个动作都有音效与触感反馈
25. **💡 卡关求助的最后一格**：同一关连续 2 次 0 星后，结算页出现「查看精确参数分解」；展开后除了参数文本，还有一个**「✨ 一键套用这些参数」**按钮——把精确解直接落到编辑态并回到调参界面，卡住的玩家不用手抄 8 根指针（可撤销）
26. **🎉 本周全勤**：每日挑战的 7 日格全部点亮时，右侧文案变成金色的「🎉 本周全勤」
    - **重玩已通关的关卡也有"下一关 →"**：首次通关有「🔓 下一关已解锁」庆祝，
      但重玩刷三星时下一关早就解锁了、那条不会出现——补一条收敛配色的「下一关 →
      继续前进」，推进路径不再断（随机关 / 每日 / 末关不显示）
27. **🏅 通关战利品墙**：结局面板按章列出**全部 21 关的真实轮廓**（左侧标着章名）——拿过星的点亮（青），三星的描金，集齐的章在右侧盖上章节印；一屏看完自己画过的所有曲线（轮廓点串与图鉴共用 shapes.ts）。墙是**逐关点亮**的：21 个轮廓错峰淡入（每关错开 55ms），像一路走过来的回放。**每格悬停会冒出关卡名**（静态堆 21 个名字会挤成一团），并带 `aria-label`（如「九瓣花：3 星」）供读屏。**每格都是一个按钮，点一下直接载入那一关再玩**（演出关掉、回到调参界面）
28. **📳 移动端触感反馈**：升星（三星更重）、盖章、章节印、成就解锁、通关各给一次振动（Android Chrome 等支持；iOS 不支持则静默忽略）。只在这些"奖励时刻"震，收集音那样的高频反馈不震——跟着音效开关走
29. **📆 每日打卡墙（统计页）**：最近 **5 周**的打卡日历（按周一对齐，今天描青边，未到的日期压暗），上方一行给出**累计天数 / 当前连续 / 历史最长连续**（最长连续由每日成绩反推），右侧还有一枚进度胶囊——「距『月月有余』还差 N 天」，连满 30 天变成「🏅 月月有余已达成」——比 7 日格更能看出长期习惯
30. **⚙️ 设置面板**：底部工具栏的 ⚙️ 一处集中——**音效 / 背景音乐 / 音量 / 专家模式 / 随机与每日难度 / 减少动画**，附快捷键说明。**减少动画**会关掉抖动、弹动与错峰入场（用一条全局兜底把所有动画压到瞬时，以后新增的动画也不会漏），系统开了"减弱动态效果"时默认打开。**音量三态（满 / 半 / 静音）会真正持久化**：静音是合法值 0，读取时不能当成假值回落到满音量；且启动时要把存档音量灌进音频模块的模块级状态，否则上次静音的玩家一刷新就会突然有声音（这两条都有单测兜着）
31. **🎯 上届漏点提示**：跑完一局回到调参界面时，**上一局没扫到的点用红色虚线圈标出**，画布底部同时写「预览收集 X/Y · 上届漏 N 点（红圈）」——一边调参一边看"这次能不能把上次漏的补上"（这次预览能扫到的点会被金色预览圈接管，等于当场看到补上了）。换关后提示自动失效，不会把上一关的漏点画到新关上
32. **🌀 第六章 · 巧变**（风车 / 双旋 / 云纹）：频率清单不变，只改**振幅配比与相位**就是另一件器物——风车靠一根 −3× 反转拧出四叶、双旋靠 1×/3×/−1× 的配比定两瓣胖瘦、云纹靠 4× 与 7× 两级摆动展开出 +5×/−3×/+8×/−6× 叠成云头。本章调性 F 商五声（换宫音再取一调，与五章根音各不相同）
33. **🏛 第七章 · 大成**（灯笼 / 团花 / 古钟）：终章把前六章的功夫合起来用——三项式半径 r = a + b·cos2kθ 乘上 e^{iθ}，展开后成套的频率一起上：灯笼 5 根（1×/3×/5×）、团花 7 根（2×/4×/5×/7×）、古钟 7 根（1×/3×/5×/7×）。本章调性升 F 宫五声（185 Hz，音阶第 4 号音仍在 700 Hz 上限内，抵达音三声俱全）
34. **📱 触屏适配**：手机上所有可点控件热区 ≥40px（章节圆点视觉仍是 8px，但按钮本体撑到 40×40；章节翻页、难度档、生成/创作、面板标签、设置开关、步进按钮同理）；竖屏运行栏重排为「5 个功能键一行 + 4 个图标键一行」，不再出现单个图标被挤到下一行的孤儿；纯图标按钮补上 aria-label（音量 / 音乐 / 成就 / 设置，状态随开合变化）；**平板宽度（768 / 1024）也扫过一遍**——修掉了难度档被压到 33px 后「简单 / 普通 / 困难」逐字竖排、以及引导条「第 1 步」被压成两行的问题（窄视口经典坑：CJK 没有断点，容器一窄就一字一行；现在四个宽度下都有探测器兜底）。**手机横屏（844×390 / 900×414 / 640×360）单独修过**：中屏断点把 main 设成了 grid，而横屏块只写了 flex-direction，于是 `main` 仍是 grid、`.sides{width:0}` 把面板压成 0 宽（侧栏只剩 11px、中文逐字竖排）；现在横屏显式 `display:flex`，舞台与画布同宽，运行栏排两行（5 功能 + 4 图标）不再被裁到屏幕外，引导条在横屏收起（内容在右侧关卡提示里有）。**矮屏弹层（横屏 ~390px 高）也要能滚**：成就 / 设置 / 合成器 / 通关演出 / 入境卡原本用 vh 或干脆没设上限，实测 430px 高的弹层在 390px 屏上**上下都被裁掉**（顶部标签栏与底部按钮都够不着）——统一改成 max-height: calc(100dvh - 24px) + overflow-y: auto，实测滚动后按钮可达。**横屏面板分两栏**：单列时面板区 scrollHeight 1668px，要滚过整个关卡面板才够到指针面板——现在横屏两栏并排、左右各自滚动（各 ~250px 宽），窄到放不下时自动回落到单列
35. **💾 备份口径**：存档（成就面板 → 存档）覆盖**全部持久化数据**——星级 / 最佳分 / 最快全清 / 完美与精确认证 / 每日成绩与连胜 / 成就与行为标记 / 解法存档 / 上届节奏 / 卡关次数 / 合成器草稿 / 音量音效音乐；其中**偏好类（音量 / 音效 / 音乐 / 难度 / 合成器折叠偏好）在“清空进度”时保留**，其余进度一律清掉。新增持久化数据时有单测兜底（constants 里声明的每个存储键都必须登记进存档表）
36. **🗓 本周挑战**：seed 由 **ISO 周键**（年 + 周序号）决定，固定**困难档**——同一周全球玩家同关，一周里慢慢磨；「🗓 每周挑战」按钮显示本周最佳分，「📤」分享 `#w=<难度>` 链接，好友打开即进同一周的同一条曲线。新一周自动换新曲线（周键变化，seed 跟着变）；按钮右侧显示「还剩 N 天」（`daysLeftInWeek`，ISO 周一为始、含今天）

内置关卡不是一串并列按钮，而是一条通关路线：

## 音效与音乐

傅立叶级数本来就是声音的语言，所以声音不是装饰，而是**同一套数学的听觉通道**。配乐的目标听感是"探索未知"：**没有持续低鸣**，只有稀疏、偶发的声音和一片空旷的空间，安静下来几乎只剩空间感。

| 层次     | 听感                                   | 实现                                                                                                                                   |
| -------- | -------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| 远方信号 | 每隔几秒飘出一条五声乐句，像笛箫的短句 | **中国风旋律动机**（级进回绕 + 尾音拖腔）+ 编钟泛音（低音带钟味，超 700 Hz 的泛音自动跳过）；起音 0.3~0.7 秒、随机声像；句间留白 ≥6 秒 |
| 你的指针 | 转起来时，指针是一阵阵风铃脉冲的织体   | 每根指针按自己的节拍（1.6~3.6 秒）敲一下：频率 \|k\| → 第 k 次谐波（超 700 Hz 降八度）、半径 → 音量、相位 → 声像；无任何持续振荡器     |
| 空气     | （已移除——持续噪声就是"嗡嗡"的来源）   | 无                                                                                                                                     |
| 空间     | 空旷、遥远                             | 短混响（1.4 秒指数衰减，湿 0.3）+ 单次回声（0.42 秒，湿 0.15，无反馈），干湿并联                                                       |
| 收集     | **古筝式拨弦**（带上滑音），音阶上行   | 极快起音（6 ms）+ 指数衰减 + 三个泛音（1 : 0.3 : 0.12）+ 50 ms 上滑音装饰；全清奏**本关调性的古筝刮奏**（五声上行一行）                |
| 木鱼     | 连击每满 5 的一声轻"笃"                | 短促正弦、音高瞬间下落（880 → 620 Hz）、70 ms 衰减——中国打击乐的轻点缀                                                                 |
| 盖章     | 朱印落在结算卡上                       | 150 Hz 正弦的一声闷响（印面落纸）+ 40 ms 后一声 784 Hz 轻铃；每盖一枚错开 260 ms，音量刻意压在收尾和弦之下                             |

**不刺耳是硬约束**（高频纯音叠起来最容易扎耳朵）：

- 高次谐波按 `1 / (1 + 0.3(k-1))` 衰减——10× 只剩基频的 27%，16× 只剩 19%
- 环境音总线低通 900 Hz、实际发声音高上限 700 Hz；音效总线另有自己的低通
- 指针织体全是**短促的风铃脉冲**（1.6~3.6 秒一次，寿命 <8 秒），没有持续振荡器——
  旧版"10 根指针常鸣叠加"虽实测 2.5 kHz 以上能量只占 ~1%，但持续低频叠加本身听久了就是"嗡嗡"，已从根上移除

**每章一种中国五声调式**：C 宫五声 / A 羽五声 / D 商五声 / E 角五声——五声无半音、无导音，本身就温润；切章时指针声部、收集音效、环境音一起转调，切关另有一声柔和的"抵达"泛音（编钟泛音）；随机关与每日关按邀请码稳定散列挑调性（同一关卡每次进来都一样）。微调式（徵）留给后续章节。。**所有环境音（含切关抵达音、高五度叠音）的实际发声音高都压在 700 Hz 以下**——上限卡的是含编钟泛音（×2、×2.76）之后的真实音高，不是基频；这条有单测逐一守住（曾漏过一次：700 Hz 基频配 ×2.76 泛音实际发到 1932 Hz）

浏览器自动播放策略要求手势，故音乐与音效在**首次点击/按键后**才起播（起播时会立刻同步当前状态）；切到后台自动挂起，排程同时暂停以免在挂起期间堆叠。

## 数学原理

指针链尖端位置（复平面表示）：

    P(t) = Σₖ rₖ · e^(i·ωₖ·t + φₖ)，ωₖ = 2π·fₖ / T0

这正是傅立叶级数的合成形式。任意周期曲线都可分解为有限个旋转向量之和——玩家的任务就是逆向找出这组系数。

## PWA

线上为可安装的 PWA：手机浏览器菜单「添加到主屏幕」后可全屏运行，**离线也能玩**。

- `public/manifest.webmanifest` — standalone 显示、深色主题、192/512/maskable 图标
- `public/sw.js` — Service Worker：
  - 导航与 manifest：**network-first**（保证新版本可见），断网回退缓存
  - `/assets/*`、图标：**cache-first**（文件名带指纹，内容不可变）
- 图标由 `icon.svg` 通过 headless Chrome 栅格化生成（192/512/180/32）
- 仅生产构建注册 SW（dev 下不注册，避免缓存干扰开发）

### 设计约束速查（改这些地方前先读）

这几条都是踩过坑之后固化的，改动前先想清楚，相关单测会兜底：

- **音频一切以"实际发声音高 ≤700 Hz"为准**：环境音的基频、编钟泛音（×2、×2.76）、
  指针声部（根音 × 谐波次数）分别在三处判断—— `music.ts` 的 playSwell / `harmony.ts` 的 armToVoice。
  环境音取音靠音量衰减，指针脉冲超限则**降八度**（calmFreq，保住谐波类关系）。
- **绝不加回持续音**：指针声部用排程的风铃脉冲（scheduleVoiceChimes），不用常鸣振荡器——
  持续正弦叠加（哪怕和声悦耳）听久了就是"嗡嗡"；updateMusic 只更新快照与总线响度。
- **环境音要"稀疏 + 短"**：不要加回空气噪声层、反馈回声与长混响——
  那会把稀疏的音糊成持续背景，正是"嗡嗡"的来源。
- **全局快捷键让路三件事**：正在打字（isTypingTarget）、有弹层开着（.modal / .finale /
  .ch-intro / .title-screen / .tutorial 任一存在）。新增覆盖层时记得加进这个选择器。
- **撤销栈**：`pushArmHistory` 的合并规则是"拖拽会话中合并 + 600ms 窗口合并 +
  整块动作（force）后另开一步"。**别用 MAX_SAFE_INTEGER 之类的时间戳戏法表达"禁止合并"**——
  那会让撤销栈从此长不出来（2026-10 修过一次）。
- **三态值不能用 `|| 默认` 读回**：音量的静音是合法值 0，`Number(x) || 1` 会把它当缺失；
  用白名单校验（audio.test.ts 有兜底）。
- **存档读写走 `readJson` / `writeJson` 这一对**（save.ts）：键缺失/坏 JSON/存储不可用
  都安全回落，新字段照抄一行即可。**例外**：哨兵值（音效/音乐的 '0'）与裸字符串
  （难度 DIFF_KEY）不是 JSON 语义——保持直读直写且 try/catch 不能省，
  否则无 localStorage 的测试环境 import 引擎单例时会当场炸。
- **新增 localStorage 键必须登记**进 `save.ts` 的 SAVE_KEYS / PREF_KEYS，
  否则备份恢复会丢、清空也清不干净（登记兜底测试会失败）。
  实例：难度键 DIFF_KEY 曾硬编码在 engine 里、没登记——备份导出丢难度偏好（2026-10 修）。
- **新增章节选调性先过音域检查**：scaleNotes 的第 4 号音（抵达音用到）必须 ≤700 Hz，
  否则会被 playSwell 整个静音——A 宫 220 的第 4 号音 740 Hz 就因此落选，
  第七章改用升 F 宫 185（harmony.ts 有注释）。
- **成就口径**："全部内置关卡…"类成就必须按 builtInIds 过滤——
  随机关 / 每日关 / 创作关的成绩与内置关同表存放，不过滤就会被冒充进度。
- **合成器的表达力边界**：每行是单侧旋转向量 mag·e^{i(kt+φ)}——±k 成对相加
  才抵消虚部成"实曲线"。20 槽位（⟳/⟲ 各 10）支持成对创作，但**单一行无法复现
  实值曲线**——「取当前关主频」导入的是频率指纹，画布预览即所得（topHarmonics）。
- **窄视口 CJK**：容器一窄，两字标签会逐字竖排（没有断点）——
  给标签 `white-space: nowrap` + `min-width`，宁可让旁边的内容换行。
- **媒体查询里的覆盖规则要放在样式块末尾**（同特异性靠顺序取胜），
  放在基础规则之前会被后者盖回去（2026-10 踩过：横屏 / 移动端的覆盖全部失效）。
- **改造弹层/容器结构时，先跑 div 深度追踪再提交**（aa99e9c 的连胜提示改造吞掉了
  `.dweek` 的闭合 `</div>`，尾部替位让总数恰好平衡——svelte-check 平静、浏览器容错、
  十几轮后才发现）。改完用深度脚本核对「final-depth=0 且无未闭合」再验证。
